# V62 — Portfolio Multi-Fund Overview

## สิ่งที่เพิ่มจาก V61
- เพิ่มปุ่ม `📊 ภาพรวมพอร์ต` ในหน้า Finance > My funds
- รวม Portfolio จากทุกกองทุนที่มีอยู่ใน `DATA.funds`
- แสดงต่อกองทุน: ผู้ถือ, เงินลงทุนที่มีหน่วยจริง, จำนวนหน่วย, NAV ล่าสุด, มูลค่าปัจจุบัน, P/L และผลตอบแทน
- รวมยอด Portfolio ที่คำนวณได้จากรายการที่มีหน่วยจริง
- แยกสถานะกองทุนที่คำนวณครบกับกองทุนที่ยังมีรายการรอ NAV/หน่วย
- ใช้จำนวนหน่วยจริงจาก transaction และ NAV ล่าสุดจาก `FUND_NAV`
- ไม่สร้าง transaction ใหม่ และไม่เขียนข้อมูล Google Sheets จากปุ่มภาพรวม
- คงกราฟประวัติพอร์ตจาก V61 ซึ่งใช้ transaction + NAV History จริง

## สูตร
- มูลค่าปัจจุบัน = จำนวนหน่วยจริง × NAV ล่าสุด
- P/L = มูลค่าปัจจุบัน − เงินลงทุนของรายการที่มีหน่วยจริง
- Return % = P/L ÷ เงินลงทุนของรายการที่มีหน่วยจริง × 100
- รายการที่ยังไม่มี Purchase NAV/Units จะไม่ถูกเดา และไม่รวมในยอดมูลค่า/P&L ที่คำนวณได้

## วิธี QA
1. เปิด Finance > My funds
2. กด `📊 ภาพรวมพอร์ต`
3. ตรวจว่าทุกกองทุนที่มีรายการลงทุนปรากฏในตาราง
4. ตรวจยอดรวมเทียบกับการคำนวณรายกองทุน
5. ตรวจผู้ถือของแต่ละกองทุน
6. ถ้ามีกองทุนที่ยังไม่มีหน่วย ให้สถานะแสดง `รอหน่วย` แทนการสร้างค่าปลอม
7. กด `↻ อัปเดต` แล้วเปิดภาพรวมอีกครั้งเพื่อยืนยันว่าข้อมูลหลัง sync ยังตรงกัน

## หมายเหตุ
- V62 เป็นชั้นแสดงผล/ตรวจสอบ Portfolio รวมหลายกองทุนต่อจาก V61
- ไม่เปลี่ยน schema ของ Investments และไม่เปลี่ยน NAV updater
