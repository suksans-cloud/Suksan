# V63 — Real Transaction Portfolio Reconciliation

## เป้าหมาย
V63 ต่อจาก V62 โดยแยกข้อมูล “เงินลงทุนตามแผน” ออกจาก “รายการซื้อจริง” ให้ชัดเจน และเพิ่มหน้าตรวจสอบ transaction จริง

## เพิ่ม
- ปุ่ม `🧾 รายการซื้อจริง` ใน Finance > My funds
- แสดงรายการซื้อจริงจาก `Investments`/DATA.funds ที่มี transaction
- แสดงวันที่ซื้อ, กองทุน, ผู้ถือ, เงินซื้อ, NAV ซื้อ, หน่วย, NAV ล่าสุด, มูลค่าปัจจุบัน, P/L และผลตอบแทน
- รายการที่ยังไม่มีหน่วยหรือ NAV ล่าสุดจะแสดง `รอหน่วย/NAV` และไม่ถูกเดา
- สรุปยอดคำนวณเฉพาะ transaction ที่มีหน่วยและ NAV ล่าสุด
- PlanMaster/เงินลงทุนตามแผนยังคงแยกออกจากเงินจริง

## ความหมายของภาพ V62 ที่เห็น
- `เงินลงทุนตามแผน ฿172,700` คือแผน/งบลงทุน ไม่ใช่เงินที่ซื้อจริงทั้งหมด
- `เงินลงทุนที่มีหน่วย ฿2,000` คือ transaction จริงที่มีหน่วยแล้ว
- เมื่อมีการซื้อกองทุนเพิ่มและบันทึก transaction จริง ตัวเลข Portfolio และกราฟจะเพิ่มตาม transaction จริง

## สูตร
- มูลค่าปัจจุบัน = หน่วยจริง × NAV ล่าสุด
- P/L = มูลค่าปัจจุบัน − เงินซื้อของ transaction ที่มีหน่วย
- Return % = P/L ÷ เงินซื้อ × 100

## QA
1. เปิด Finance > My funds
2. กด `🧾 รายการซื้อจริง`
3. ตรวจ SCBNK225E รายการ ฿2,000 / 38.2438 หน่วย
4. ตรวจยอดรวมต้องเท่ากับหน้า Portfolio
5. ตรวจว่า `฿172,700` ยังแสดงเป็นเงินลงทุนตามแผน ไม่ถูกนับเป็นเงินจริง
6. เพิ่ม transaction จริงภายหลังแล้วกด `↻ อัปเดต` เพื่อให้รายการใหม่เข้าระบบ

V63 ไม่สร้าง transaction และไม่เขียนข้อมูลลง Google Sheets จากหน้าตรวจสอบนี้
