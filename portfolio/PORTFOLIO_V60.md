# V60 — Purchase NAV P&L QA

## สิ่งที่เพิ่มจาก V59
- เพิ่มปุ่ม `🧮 ทดสอบ P/L` ในหน้า Finance
- เพิ่ม QA จำลองการซื้อ 1 รายการ โดยใช้ NAV ย้อนหลังจริงจาก `FundNAV_History`
- ใช้ NAV ปัจจุบันจริงในการประเมินมูลค่าปัจจุบัน
- แสดงสูตร `Units = Amount / Purchase NAV`, `Value = Units × Current NAV`, `P/L = Value − Amount` และผลตอบแทน %
- ไม่สร้าง transaction จริง และไม่เขียน `Investments` หรือ Google Sheets
- เลือกกองทุนที่มี NAV History อย่างน้อย 2 วันที่แตกต่างกัน โดยให้ SCBNK225E เป็นลำดับแรกเพื่อ QA ที่ทำซ้ำได้
