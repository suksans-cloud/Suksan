Google Sheets
ยังไม่ได้เชื่อมต่อ
ต้องเปิด Google Sheets API และตั้ง Authorized JavaScript origins ของ OAuth Client ให้ตรงกับเว็บนี้ หากใช้ไฟล์ HTML ให้รันผ่าน localhost หรือเว็บโฮสต์ ไม่ใช่ file://
เมื่อเชื่อมต่อแล้ว แอปจะดึงข้อมูลใหม่จาก Sheets ให้อัตโนมัติทุก ~25 วินาที (ตอนแอปเปิดอยู่) และดึงทันทีเมื่อสลับกลับมาที่แท็บนี้ — แก้ไขตัวเลขในชีตแล้วจะขึ้นในเว็บให้เองโดยไม่ต้องกด "ดึงจาก Sheets"
