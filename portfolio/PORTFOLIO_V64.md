# V64 — Real Portfolio Daily History

## เป้าหมาย
เปลี่ยนกราฟ “ประวัติพอร์ต” จากการแสดงเฉพาะวันที่มี transaction/NAV เป็นการประเมินมูลค่าพอร์ตแบบรายวัน ตั้งแต่วันซื้อจริงรายการแรกจนถึงวันล่าสุดที่มี NAV จริง

## หลักการ
- ใช้เฉพาะ `Investments`/`DATA.funds` ที่มี transaction และจำนวนหน่วยจริง
- ไม่ใช้ `PlanMaster` เป็นเงินลงทุนจริง
- ใช้ `FundNAV_History` ของแต่ละกองทุนเพื่อหา NAV ล่าสุดที่มีจริง ณ แต่ละวัน
- NAV วันหยุด/วันที่ไม่มี NAV จะ carry-forward เฉพาะ NAV จริงล่าสุดก่อนหน้านั้น
- หากกองทุนใดไม่มี NAV ที่ใช้คำนวณ ณ วันนั้น จะไม่สร้างมูลค่าปลอม และจะแจ้งว่า history ยังไม่ครบ
- เงินลงทุนสะสมเพิ่มเฉพาะวันที่มี transaction จริง

## กราฟ
- เส้น “มูลค่าพอร์ต” = จำนวนหน่วยจริง × NAV จริง ณ วันนั้น
- เส้น “เงินลงทุนสะสม” = ยอดเงินซื้อจริงสะสมตามวันที่ซื้อ
- เมื่อมีเพียง transaction เดียว กราฟจะแสดงประวัติรายวันตั้งแต่วันที่ซื้อถึงวันที่มี NAV ล่าสุด ไม่ใช่จุดเดียว
- ถ้ามีหลายกองทุน จะรวมมูลค่าจากทุกกองทุนที่มีหน่วยจริงในแต่ละวัน

## QA
1. เปิด Finance > My funds
2. ตรวจกราฟ `ประวัติพอร์ต`
3. รายการซื้อ SCBNK225E วันที่ 29/09/2026 ฿2,000 / 38.2438 หน่วย ควรทำให้กราฟมีช่วงวันที่ตั้งแต่ 29/09/2026 ถึงวันล่าสุดที่มี NAV
4. เส้นเงินลงทุนสะสมควรเริ่มที่ ฿2,000 หลังวันซื้อ
5. มูลค่าพอร์ตควรคำนวณจาก 38.2438 หน่วย × NAV จริงของแต่ละวัน
6. เพิ่ม transaction จริงภายหลังแล้วกด `↻ อัปเดต` กราฟต้องขยายและรวมรายการใหม่

V64 ไม่สร้าง transaction และไม่เขียนข้อมูลลง Google Sheets จากกราฟ
