# V65 — Portfolio History Entry Point

แก้ปัญหาผู้ใช้หา “ประวัติพอร์ต” ไม่เจอใน V64

- เพิ่มปุ่ม `📈 ประวัติพอร์ต` ใน Finance
- กดแล้วพาไปยังการ์ด “ประวัติพอร์ต” โดยตรง
- ถ้าอยู่ ETF/Stock จะสลับกลับ My funds ก่อน
- ใช้ข้อมูลธุรกรรมจริง + NAV History จริงเหมือน V64
- ไม่ใช้ PlanMaster เป็นเงินลงทุนจริง
- ไม่สร้างหรือแก้ transaction จริง
